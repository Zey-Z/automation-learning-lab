# Automation Learning Lab

A structured 6-week learning workspace for building practical automation engineering skills.

## Folder Structure

| Folder | Purpose |
|--------|---------|
| `plan/` | Learning roadmap, weekly plans, current week focus |
| `concepts/` | Concept notes organized by week, plus a glossary |
| `exercises/` | Exercises generated by the tutor, organized by week |
| `submissions/` | Your answers, code, and working notes |
| `feedback/` | Tutor reviews and revision suggestions |
| `question-bank/` | Reusable drill sets by topic (JS, API, SQL, etc.) |
| `projects/` | Mini-projects simulating real business automation tasks |
| `.claude/` | Claude Code commands, agents, and settings |

## How to Use

1. Open this folder in your terminal
2. Run `claude`
3. Use `/today` to start a study session
4. Use `/drill [topic]` for focused practice
5. Use `/review-work` to get feedback on your submissions
