# Standard Rubric

Every exercise is evaluated on:

| Criteria | Description |
|----------|-------------|
| Correctness | Does the code produce the expected output? |
| Clarity | Is the code readable and well-structured? |
| Robustness | Does it handle edge cases and bad input? |
| Reasoning | Can the student explain why their solution works? |

## Scoring
- 1-3: Needs significant revision
- 4-6: Partial understanding, key gaps remain
- 7-8: Solid, minor improvements needed
- 9-10: Job-ready quality

## Per-Week Mastery Criteria

### Week 1: JS Foundations
- Use array methods (map/filter/reduce) without reference
- Parse JSON and handle missing keys
- Identify error types from error messages

### Week 2: APIs + Python
- Explain HTTP methods and status codes with real examples
- Construct API requests with correct headers/body
- Write Python functions that process and return data

### Week 3: SQL
- Design a multi-table schema with keys and constraints
- Write SELECT/JOIN/GROUP BY queries without reference
- Explain normalization and write upsert statements

### Week 4: Webhooks + Reliability
- Explain webhook vs polling with a scenario
- Implement retry with exponential backoff from scratch
- Explain and implement idempotency

### Week 5: End-to-End
- Pipeline runs end-to-end without manual intervention
- Handles 3+ failure scenarios gracefully
- Every step logs input and output

### Week 6: Documentation + Delivery
- README is understandable by someone new to the project
- Setup guide produces a running system from scratch
- Handoff note explains design decisions, not just instructions
